# 用唯一索引兜住文件表的重复写入

<!-- content-workspace-job:23ed672c-d8dc-42fe-be59-aea59b8bcdda -->

## 问题场景

文件表的写入先查后插，两个并发请求同时查到不存在，于是各插了一条。业务侧统计翻倍，清理时又不敢确定哪条该留。

## 实现步骤

在业务唯一键上建唯一索引，让数据库来保证不重复。

```sql
ALTER TABLE files ADD UNIQUE KEY uk_bytes (bytes);
```

写入改成先尝试插入，冲突时按业务决定忽略还是更新。

```sql
INSERT INTO files (id, bytes) VALUES (1, 2048)
ON DUPLICATE KEY UPDATE bytes = VALUES(bytes);
```

确认索引真的生效，冲突时应当报 1062 而不是静默成功。

```sql
SELECT COUNT(*) FROM files WHERE bytes = 100;
SHOW INDEX FROM files WHERE Key_name = 'uk_bytes';
```
