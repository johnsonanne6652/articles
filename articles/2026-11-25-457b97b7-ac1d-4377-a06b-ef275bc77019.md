# 题目主题切换只改 CSS 变量不动结构

<!-- content-workspace-job:457b97b7-ac1d-4377-a06b-ef275bc77019 -->

## 问题场景

题目后台要支持深浅两套主题，原先每个组件都写死了颜色，改一次要动几十个文件。

## 实现步骤

在根选择器上定义颜色变量，组件样式一律引用变量而不是字面值。

```css
:root {
  --bg: #ffffff;
  --fg: #1f2328;
  --line: #d8dee4;
}
:root[data-theme="dark"] {
  --bg: #16181d;
  --fg: #e6edf3;
  --line: #30363d;
}
```

切换主题时只改根节点的类名，由类名覆盖变量取值。

```javascript
.card {
  background: var(--bg);
  color: var(--fg);
  border: 1px solid var(--line);
  padding: 12px 16px;
}
```

把选择结果写入本地存储，刷新后先读回再渲染，避免闪白。

```javascript
const root = document.documentElement;
function apply(mode) {
  root.dataset.theme = mode;
  localStorage.setItem('question-theme', mode);
}
```

## 注意事项

变量要定义在包含所有组件的作用域上，写在组件内部无法被全局覆盖；内联样式优先级更高，会盖掉变量。

考虑到线上环境的差异，需要同时关注错误率与延迟两个指标，便于横向对比不同方案的效果。

在跨团队协作时，建议在变更前留一份可回滚的快照，避免资源被长期占用。

经过几轮迭代后，建议先在预发环境跑一轮完整流程，保证每一步都可验证。
