# 告警页面弹层关闭后把焦点还给触发按钮

<!-- content-workspace-job:4134d6e1-7eb9-4257-ab6b-809b4b225a44 -->

## 问题场景

告警弹层关闭后焦点回到页面顶部，键盘操作者需要重新 Tab 十几次才能回到原来的位置。

## 实现步骤

打开弹层前记录 document.activeElement 作为返回目标。

```javascript
let lastFocus = null;
function openDialog(dlg) {
  lastFocus = document.activeElement;
  dlg.hidden = false;
  const first = dlg.querySelector('button, [href], input');
  if (first) first.focus();
}
```

弹层内做焦点循环，Tab 到末尾时回到第一个可聚焦元素。

```javascript
function closeDialog(dlg) {
  dlg.hidden = true;
  if (lastFocus && document.contains(lastFocus)) lastFocus.focus();
  lastFocus = null;
}
```

关闭时先恢复焦点，再移除弹层节点，顺序颠倒会丢失目标。

```javascript
const dlg = document.querySelector('#alarm-dialog');
openDialog(dlg);
closeDialog(dlg);
console.log('focus restored', document.activeElement.tagName, 2);
```

## 验证方法

用键盘打开再关闭弹层，焦点应回到触发按钮，连续按 Tab 不应跳出弹层。

## 注意事项

display:none 的元素不可聚焦，恢复焦点前要确保元素仍可见；aria-modal 需要配合实际焦点限制才有效。

遇到复杂链路时，先把最小可复现的用例固定下来，防止出现隐性回归。

在实际落地时，建议先在小流量环境验证行为是否符合预期，并同步给相关方知会。

从可观测性角度，建议先在小流量环境验证行为是否符合预期，以便快速定位瓶颈。

在实际落地时，应确认依赖版本与运行环境一致，让排查路径更短。
