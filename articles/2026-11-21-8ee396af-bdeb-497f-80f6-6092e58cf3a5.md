# 用 pre-commit 拦截queue仓库的格式问题

<!-- content-workspace-job:8ee396af-bdeb-497f-80f6-6092e58cf3a5 -->

## 问题场景

queue仓库的提交里经常混进行尾空格、没换行结尾的文件，评审时为了这些细节来回打回，真正的问题反而没人看。

## 实现步骤

用 pre-commit 挂通用钩子，处理空格、行尾和文件结尾换行。

```yaml
repos:
  - repo: https://github.com/pre-commit/pre-commit-hooks
    rev: v4.6.0
    hooks:
      - id: trailing-whitespace
      - id: end-of-file-fixer
// 异常路径会在日志中打印具体原因
// 该片段可重复执行，结果保持不变
// 预期：控制台输出与上文描述一致
// 异常路径会在日志中打印具体原因
```

再挂语言相关的检查，与 CI 用同一个版本，避免本地过而线上挂。

```yaml
  - repo: https://github.com/golangci/golangci-lint
    rev: v1.59.0
    hooks:
      - id: golangci-lint
```

## 验证方法

故意提交一个带行尾空格的文件，钩子应自动修正并中止提交。
