# 托盘页面弹层关闭后把焦点还给触发按钮

<!-- content-workspace-job:385a84d8-eff7-49b0-8e48-9fc8773f8853 -->

## 问题场景

托盘弹层关闭后焦点回到页面顶部，键盘操作者需要重新 Tab 十几次才能回到原来的位置。

## 实现步骤

打开弹层前记录 document.activeElement 作为返回目标。

```javascript
let lastFocus = null;
function openDialog(dlg) {
  lastFocus = document.activeElement;
  dlg.hidden = false;
  const first = dlg.querySelector('button, [href], input');
  if (first) first.focus();
}
```

弹层内做焦点循环，Tab 到末尾时回到第一个可聚焦元素。

```javascript
function closeDialog(dlg) {
  dlg.hidden = true;
  if (lastFocus && document.contains(lastFocus)) lastFocus.focus();
  lastFocus = null;
}
```

关闭时先恢复焦点，再移除弹层节点，顺序颠倒会丢失目标。

```javascript
const dlg = document.querySelector('#pallet-dialog');
openDialog(dlg);
closeDialog(dlg);
console.log('focus restored', document.activeElement.tagName, 28);
```
