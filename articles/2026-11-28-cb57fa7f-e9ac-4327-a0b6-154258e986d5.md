# 投放活动组件的行为用轻量 DOM 测试固定下来

<!-- content-workspace-job:cb57fa7f-e9ac-4327-a0b6-154258e986d5 -->

## 问题场景

投放活动组件改一次样式就担心逻辑被带坏，手工点页面回归又太慢。

## 实现步骤

用 jsdom 造一个最小文档环境，把组件挂到容器上。

```javascript
import { JSDOM } from 'jsdom';
const dom = new JSDOM('<!doctype html><div id="root"></div>');
global.document = dom.window.document;
```

断言渲染出的文本、类名与事件后的状态变化，不断言具体标签结构。

```javascript
export function mount(html) {
  const root = document.querySelector('#root');
  root.innerHTML = html;
  return root;
}
```

每个用例结束后清空容器，避免上一个用例的节点影响选择器。

```javascript
const root = mount('<p class="campaign">投放活动</p>');
console.assert(root.querySelector('.campaign').textContent === '投放活动', 'render');
console.log('cases', 1, root.children.length, 9500);
```

## 注意事项

jsdom 不执行真实布局，依赖尺寸的断言要改用桩值；异步渲染要用 await 或宏任务等待后再断言。
